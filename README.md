# 💰 Kişisel Harcama Analizi Projesi

Bu proje, kişisel harcamaları analiz etmek ve görselleştirmek amacıyla hazırlanmıştır.  
Veriler **expenses.csv** dosyasında tutulur ve analiz işlemleri **Jupyter Notebook** üzerinde yapılır.


## 📂 Proje Dosyaları

- **expenses.csv** → Örnek harcama verileri  
- **expenses.ipynb** → Python (Pandas + Matplotlib) kullanılarak yapılan veri analizi  
- **README.md** → Proje açıklaması ve çalıştırma adımları  


## 🧠 Kullanılan Kütüphaneler

- **Pandas** → Veri okuma, düzenleme ve analiz  
- **Matplotlib** → Grafik çizimi (Pasta grafiği, çubuk grafik) 
- **Jupyter Notebook** → Etkileşimli çalışma ortamı
