# 💰 Expense Analysis / Kişisel Harcama Analizi

**EN:**  
This project analyzes personal spending data using Python.  
The dataset (`expenses.csv`) includes example daily expenses, which are analyzed and visualized in a Jupyter Notebook using **Pandas** and **Matplotlib**.  

**TR:**  
Bu proje, Python kullanarak kişisel harcamaları analiz etmek ve görselleştirmek amacıyla hazırlanmıştır.  
Veriler `expenses.csv` dosyasında tutulur ve analiz işlemleri **Jupyter Notebook** ortamında, **Pandas** ve **Matplotlib** kütüphaneleriyle gerçekleştirilmiştir.

---

## 📂 Project Files / Proje Dosyaları

- `expenses.csv` → Example expense dataset / Örnek harcama verileri  
- `expenses.ipynb` → Jupyter Notebook with the analysis / Analiz yapılan Notebook dosyası  
- `README.md` → Project description and usage steps / Proje açıklaması ve kullanım adımları  

---

## 🧠 Used Libraries / Kullanılan Kütüphaneler

- **Pandas** → Data manipulation and analysis / Veri okuma ve analiz  
- **Matplotlib** → Visualization (Pie & Bar charts) / Grafik çizimi (Pasta ve Çubuk grafik)  
- **NumPy** → Numerical calculations / Matematiksel işlemler  
- **Jupyter Notebook** → Interactive analysis environment / Etkileşimli çalışma ortamı  

---

## ⚙️ How to Run / Nasıl Çalıştırılır

1. Clone or download this repository:  
   ```bash
   git clone https://github.com/<kullanici-adi>/expense-analysis.git
   ```

2. Install required libraries:  
   ```bash
   pip install pandas matplotlib numpy jupyter
   ```

3. Launch Jupyter Notebook:  
   ```bash
   jupyter notebook
   ```

4. Open `expenses.ipynb` and run the cells step by step.

---

## 📊 Analysis Steps / Analiz Adımları

- Read CSV file (`read_csv`)  
- Analyze total expenses by category  
- Visualize percentage distribution (Pie chart)  
- Compare spending categories (Bar chart)  
- Calculate summary statistics (`unique`, `value_counts`, `describe`)
